# 海淀青年人才安居补贴填报助手

适用页面：北京市政策兑现网站 `https://zhengce.beijing.gov.cn/` 内，标题为“2026年海淀区青年人才安居补贴（申请人）”且包含对应基本信息字段的表单。扩展不依赖 `add`、`edit` 路径或申请编号等网址参数；若网站改版或年度标题变化，需要重新检查脚本。

## 首次使用

1. 复制 `资料模板.json`，把副本放到你自己保管的本地目录，例如“文稿”中的非同步目录，命名为 `我的申请资料.json`。不要把填有身份证号、银行账号的文件发到聊天、网盘或代码仓库。
2. 用文本编辑器打开副本，在双引号之间填写。空字符串 `""` 表示跳过该字段。“毕业时间”和“参加工作时间”可以写 `YYYY-MM`；“申请日期”可写 `"今天"`，扩展填写时按北京时间计算当天日期，也可写固定的 `YYYY-MM-DD`。是/否题写 `"是"` 或 `"否"`。下拉选项应使用网页中的完整文字。JSON 不能在末尾添加多余逗号。
3. Chrome 地址栏输入 `chrome://extensions`，打开“开发者模式”，点击“加载已解压的扩展程序”，选择本文件夹 `beijing-housing-form-helper`。本扩展只在你点击图标时临时访问当前标签页，先检查网站域名，再核对表单标题和关键字段。

## 每月填写

1. 打开申请页并登录，确认当前是新的月度申请。
2. 点击扩展图标。首次使用时点击“设为默认 JSON 文件”，选择 `我的申请资料.json`；之后直接点击“填入当前申请页”。扩展记住文件访问句柄，不保存 JSON 内容。Chrome 若要求重新授权读取文件，请在点击填写时允许。也可以点击“本次选择其他 JSON 文件”；选取窗口优先从默认文件所在位置打开，否则从上次选择的位置打开，首次选择从桌面打开。浏览器不允许扩展直接指定电脑上的绝对路径，所以首次仍需手动定位一次。
3. 查看扩展列出的未完成项目，并逐项核对申请页。尤其检查日期、下拉选项、是/否、账户信息和当月可能变化的内容。
4. 核对无误后，再打开扩展点击“已核对，勾选页面承诺”。这个按钮会勾选网页中的“确认”，每次申请都需要你主动点击。
5. 自行完成“附件清单”、填写检查、暂存、下一步与最终提交。

## 范围和限制

- 扩展不会登录、上传附件、点击暂存或提交；承诺确认只在你点击专门按钮后勾选。
- 只有资料文件里填写的非空字段会被处理。页面上未找到或无法确认的字段会在弹窗里列为“需要手动处理”。
- 第 1 页的“申报主体”和“申报区划”由网站自动带出；脚本不修改。
- 日期会优先通过网页日历选择器设置；若网站改版或日期超出控件可选范围，遇到提示时手动填写即可。
- 文件内容在你点击“填入当前申请页”后会进入该政府网站的表单。选择文件前确认当前网址和资料准确。
- 点击“取消默认文件”只会清除扩展记住的文件访问句柄，不会删除你的 JSON 文件。

## 上传 GitHub 前

这个文件夹只包含扩展代码、说明、空白的 `资料模板.json` 和填有虚构内容的 `资料示例.json`。示例中的姓名、单位、地址均为演示，身份证号、电话、银行账号等使用以 `123456` 开头的虚构占位值；下拉选项也仅供说明格式，使用前须按实际网页选项修改。**不要将示例文件用于正式申请或提交。**

根目录的 `.gitignore` 只允许上述两份资料 JSON 和 `manifest.json` 进入 Git，以免误提交真实申请资料。通过 GitHub 网页上传文件时仍要自行检查文件清单；不要把已填写的个人 JSON 或证件附件放进本文件夹。

如果 Chrome 目前加载的是旧目录中的扩展，旧版可以继续使用。要改用此文件夹，请在 `chrome://extensions` 移除旧版并加载此文件夹，然后重新设置一次默认 JSON 文件。
