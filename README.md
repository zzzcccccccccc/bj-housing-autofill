# 北京住房补贴填报助手

一个用于**重复填写北京市政策兑现网站住房补贴申请表**的 Chrome 扩展。它从你自己保管的本地 JSON 文件读取资料，在你点击按钮后填入当前页面，并列出需要手动处理的项目。

> **适用范围**：目前只识别 `https://zhengce.beijing.gov.cn/` 上标题为“2026年海淀区青年人才安居补贴（申请人）”的申请表。它不是通用表单填写器，也不是政府官方工具。网站标题、字段或控件变化后，可能需要调整代码。

扩展不会替你登录、上传附件、暂存、进入下一步或提交申请。页面承诺的“确认”有单独按钮，只有你核对后主动点击才会勾选。

## 安装

无需构建或安装依赖。

1. 在 GitHub 仓库页面点击 **Code → Download ZIP**，解压到一个固定目录；也可以克隆仓库。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角的**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择包含 `manifest.json` 的目录。
4. 打开目标申请页并登录。点击扩展图标开始使用。

更新本地代码后，到 `chrome://extensions` 点击扩展卡片上的**重新加载**。如果要换一个安装目录，请移除旧目录加载的扩展，再从新目录加载；默认资料文件需要重新设置。

## 准备资料文件

1. 复制 [资料模板.json](资料模板.json)，把副本存放在**仓库目录之外**，例如你自行管理的本地非同步目录。不要把填有个人资料的 JSON、证件照片或申请附件提交到 GitHub。
2. 用文本编辑器填写需要处理的字段。所有值都必须是字符串；不需要填写的字段保留空字符串 `""`。不认识的字段名会被拒绝。
3. 保存为 `.json` 文件。可参考 [资料示例.json](资料示例.json) 的格式，但示例中的人物、单位、地址和号码都是虚构占位内容，**不能直接用于正式申请**。

常用格式：

| 字段类型 | 写法 | 说明 |
| --- | --- | --- |
| 申请日期 | `"今天"` 或 `"YYYY-MM-DD"` | `"今天"` 会在每次填写时按北京时间计算。 |
| 毕业时间、参加工作时间 | `"YYYY-MM"` | 填写年月。 |
| 是/否题 | `"是"` 或 `"否"` | 按页面实际情况填写。 |
| 下拉选项 | 页面显示的完整文字 | 不匹配时留给你手动选择。 |
| 不填写的字段 | `""` | 扩展会跳过。 |

JSON 使用英文双引号，字段之间用逗号分隔，最后一项后面不要加逗号。

## 每月使用

1. 登录北京市政策兑现网站，打开本月对应的申请表，确认页面标题和申请月份。
2. 第一次使用时，点击扩展中的**设为默认 JSON 文件**，选择你保存在仓库外的资料文件。之后点击**填入当前申请页**即可；扩展会在每次填写时重新读取该文件的当前内容。也可以点击**本次选择其他 JSON 文件**临时切换。
3. 查看弹窗显示的已填写数量和“需要手动处理”列表，逐项核对网页中的日期、选项、账户信息及当月变化的内容。页面顶部的“申报主体”和“申报区划”由网站带出，扩展不修改。
4. 确认页面内容无误后，如需使用扩展勾选承诺，再点击**已核对，勾选页面承诺**。这一步不会随普通填写自动执行。
5. 自行处理附件、填写检查、暂存、下一步及最终提交。

点击**取消默认文件**只会清除扩展记住的默认文件入口，不会删除磁盘上的 JSON。Chrome 如果要求重新授权读取默认文件，需在点击填写时允许；如果无法使用文件选择器，可用“本次选择其他 JSON 文件”临时读取。

## 资料与权限

- 扩展只申请 Chrome 的 `activeTab` 和 `scripting` 权限；点击按钮后才检查当前标签页，且仅处理指定域名、标题和关键字段匹配的表单。
- 默认文件和最近选择文件的**访问句柄**保存在浏览器本地 IndexedDB 中；扩展不把 JSON 内容持久保存到浏览器设置中。每次使用默认文件时会重新读取磁盘上的内容。
- 点击填写后，资料会进入政府网站的表单页面。请先确认网址和所选文件，再核对页面内容。扩展代码没有独立的资料上传服务。
- `.gitignore` 会忽略其他 JSON 文件，但它不能替你检查所有文件类型。提交代码前仍要查看 Git 的待提交文件清单；真实资料与附件最好始终放在仓库之外。

## 常见问题与限制

**提示“当前页面不在北京市政策兑现网站”或“没有找到完整基本信息表”**：确认网址是 `zhengce.beijing.gov.cn`、已登录且申请表加载完成。扩展要求页面包含对应的 2026 年标题和关键字段；其他年度或改版页面不会直接适用。

**某些字段被列为“需要手动处理”**：可能是页面控件未找到、选项文字不匹配，或日期控件不接受输入。请在网页上手动完成并再次核对；不要把弹窗的已填写数量当作申请已通过校验。

**修改 JSON 后没有生效**：确认弹窗显示的资料文件名；默认文件会在下次点击“填入当前申请页”时重新读取。临时选择的文件则需要重新选择。

**换了扩展安装目录**：到 `chrome://extensions` 移除旧目录加载的扩展，重新选择新目录加载，并重新设置默认资料文件。

当前代码针对特定页面结构编写。安装与脚本语法可以在本地检查，但实际填写效果需要在真实申请页面逐项核对。
